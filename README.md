# MANDATO — Edição Especial Jovem Cidadão

Esta pasta contém o site pronto para publicar no GitHub Pages. O jogo está inteiro em `index.html`; não é necessário instalar Node.js nem enviar a pasta do projeto.

## Publicar

1. Crie um repositório no GitHub ou abra o repositório onde o jogo ficará.
2. Envie `index.html`, `.nojekyll` e `README.md` para a raiz da branch `main`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione **main** e **/(root)**, e clique em **Save**.
5. Aguarde a publicação. O endereço aparecerá na própria página **Pages**.

Para atualizar o jogo depois, substitua o `index.html` no repositório.

## Funcionamento

- Imagens, fontes, estilos e código do jogo estão incorporados ao `index.html`.
- O andamento da partida é salvo no navegador usado pelo estudante.
- Ranking compartilhado e salas de turma usam a integração já configurada com Google Apps Script e precisam de conexão com a internet.
- O APK Android não é necessário para publicar o site no GitHub Pages.
